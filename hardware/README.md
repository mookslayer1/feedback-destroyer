# hardware/ (placeholder): inline pedal / box

Idea: a single-mic inline unit for speakers, worship leaders, MCs and acoustic players. LCD and real buttons for Ring Out, Lock and Bypass, running the same run-and-set process.

Open questions to settle before any design work
- Signal path: mic-level XLR in/out with phantom pass-through, or line level only?
- DSP target (a Cortex-M7 board such as Daisy, or a dedicated audio DSP) and 96 kHz operation with latency well under 1 ms.
- Noise performance of the analogue front end.
- Power: DC supply, battery, or phantom.
- CE / FCC certification and a manufacturing partner.
- Price positioning against dbx AFS2, Sabine FBX and similar.
